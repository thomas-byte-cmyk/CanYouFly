# Roadmap

Estimations en jours-homme de développement assisté par IA, hors graphismes définitifs. Détail : [`docs/DESIGN_DOSSIER.md`](docs/DESIGN_DOSSIER.md) §16.

## M1 — Conception validée ✅ *(13/11/2026)*
- Dossier de conception, documents de domaine, organisation GitHub.
- ✅ Livrable : validation écrite des décisions D1–D15.

## M2 — Prototype jouable *(≈ 21–30 j, 5–6 semaines)*
**2a. Sensation de vol** (≈ 6–8 j) — *point de validation*
- Projet Phaser 3 + TypeScript + Vite, déploiement GitHub Pages, CI (tests + poids du build).
- Physique de vol maison (poussée, portance, traînée, gravité, CG, décrochage).
- Contrôles clavier + tactile, aides au pilotage.
- Une piste, un champ, de l'eau ; atterrissage noté (5 résultats).

**2b. Prototype complet** (≈ 15–22 j) — *go / no-go « est-ce fun ? »*
- Hangar à slots, 12 catégories, ~24 pièces (placeholders), stats et équilibre visibles.
- Pilote Pip visible, 3–4 cosmétiques, états post-atterrissage.
- Étapes Paris → Reims (tuto) et Reims → Bruxelles, zones d'atterrissage, obstacles, vent, anneaux.
- Dégâts visibles, écran de résultats, 10–15 bruitages, sauvegarde minimale.

## M3 — MVP complet *(≈ 25–35 j, 6–8 semaines)*
- 8 étapes Paris → Istanbul, carte d'Europe, environnements variés.
- Économie Boulons, catalogues par ville, ~40 pièces, 3 défis/étape, 18 badges, ~50 cosmétiques.
- Événements de vol complets, sauvegarde robuste, FR + EN.
- SDK Poki (cycle de vie, interstitiels, 2 rewarded), après relecture des règles officielles.
- Graphismes : packs libres + production maison dans le style « Atelier du Dimanche » (D9 : zéro budget pour l'instant).

## M4 — Polish *(≈ 10–15 j)*
- Animations, VFX, sound design et musique, équilibrage par playtests, performance mobile, temps de chargement, nom final.

## M5 — Soumission Poki *(≈ 4–6 j + délai Poki)*
- Build final, Poki Inspector, tests de compatibilité, miniature, captures, description FR/EN, soumission.
